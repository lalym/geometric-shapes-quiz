# Геометрические фигуры — игра-викторина

Детская игра-викторина на знание геометрических фигур (на русском языке).
Картинки взяты с учебного плаката «Геометрические фигуры».

## Возможности

- **18 фигур**: 10 плоских (треугольник, квадрат, овал, круг, ромб, трапеция, пятиугольник, параллелограмм, тор) и 8 объёмных (конус, цилиндр, сфера, пирамида, куб, эллипсоид, призма, параллелепипед)
- **2 режима игры**: «Угадай название» (по картинке) и «Найди фигуру» (по названию)
- **3 раздела**: плоские фигуры, объёмные фигуры, все сразу (12 случайных вопросов)
- Счёт, шкала прогресса, конфетти за правильные ответы, звёзды в конце игры

## Структура

- `index.html` — вся игра (HTML + CSS + JS, без зависимостей и сборки)
- `shapes/` — 18 картинок фигур с плаката (PNG)

## Запуск локально

Просто откройте `index.html` в браузере.

## GitHub Pages

Settings → Pages → Source: «Deploy from a branch» → ветка `main`, папка `/ (root)`.
После этого игра доступна по адресу: https://lalym.github.io/geometric-shapes-quiz/
